    RS232 串口通訊

    即時監控接收機與飛控板之間 (Serial2, 9600 8N1) 的 JSON 字串。 TX＝接收機轉送至飛控板（含 PID 下傳與 WebSocket 命令）；RX＝飛控板回傳（遙測 / ack / evt / err）。

    TX 0 RX 0 顯示 0
